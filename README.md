# Coffe — A Quiet Place for Coffee

Website sederhana untuk kedai kopi kecil bernama Coffe di Bandung. Dibuat dengan fokus pada suasana tenang, hangat, dan jujur, bukan template kopi industrial yang ramai.

## Fitur

- Tampilan responsif, nyaman di ponsel maupun desktop
- Navigasi sticky dengan efek blur saat di-scroll
- Animasi scroll reveal di setiap section
- Counter animasi untuk statistik kedai (cangkir disajikan, pelanggan, tahun berdiri)
- Mobile menu toggle dengan ikon Font Awesome
- Hover micro-interaction di kartu menu

## Teknologi yang digunakan

- HTML5
- CSS3 (custom properties, grid, flexbox, transitions)
- Vanilla JavaScript (Intersection Observer API, requestAnimationFrame)
- Font Awesome 6 (via CDN)
- Google Fonts (Lora dan Work Sans)
